# Histórico

Este diretório contém documentos de PRs, investigações, benchmarks e estados antigos do Manga Translator.

## Regra

Arquivos daqui são **rastreabilidade histórica**, não contrato operacional vigente.

Para o estado atual, use nesta ordem:

1. [README do repositório](../../README.md)
2. [Documentação técnica canônica](../Documentação.md)
3. [Arquitetura do repositório](../ARQUITETURA_DO_REPOSITORIO.md)
4. [Plano/registro da reestruturação](../PLANO_REESTRUTURACAO.md)

Documentos históricos podem citar caminhos removidos como `tests/ci/`, `tests/package.json`, `visual-v3/`, BAT/PS1 e runners antigos. Essas referências não devem ser copiadas para código novo.
