Align the configured ratio with the explicit formula after merge unless real timing data supports retaining the stricter bound.

## Handling rule

New non-critical defects found during this phase must be appended here with reproduction evidence and deferred. Do not spend another critical slot without an explicit severity rationale and an entry in the budget above. The implementation can be reported complete only when C1 is resolved or its blocker is documented and the affected gate remains closed.
